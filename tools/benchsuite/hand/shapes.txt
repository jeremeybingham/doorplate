# The hand stratum of the benchmark suite (#75): hand-written labeled shapes, copying the forms messy real
# rows take (typed forms, mailing lists, MLS fields, PO boxes, routes, military). tools/benchsuite/hand.py
# expands them into hand.jsonl with invented streets and numbers and real city, state and ZIP combinations.
#
# count | type | tag | case | template
# A template word is TEXT/LABEL: the label applies to every token of the text; LABEL1+LABEL2 labels each token
# in turn (the counts must match); `-` is a token that carries no label (a lone comma). Labels:
# N number, Ns number suffix, Np number prefix, pd pre-directional, pt pre-type, S street name, T post-type,
# D post-directional, Ot unit type, Oi unit id, C city, ST state, Z zip, R recipient, CN country, Bt box type,
# Bi box id, Gt route/box group type, Gi group id, Cr corner of, Is intersection separator.
# Slots: {n} {n2} number, {street} {street2} invented names, {ty} {ty2} street type ({ty.} with a period),
# {dir} {dir2} compass letters, {dirdot} dotted, {dirw} spelled, {u} {u2} unit ids, {desig} unit designators,
# {city} {city1} {st} {zip} {zip4} {stfull} a real place, {box} {route} {mnum} {rec} {ord} {ordw}, {tyt} a misspelt
# type, {cityt} a misspelt city. A slot may end in ^ (upper) or _ (lower): {street^}. Case: mixed leaves the
# template's case, lower and upper change the whole string; `spacey` joins words with 1 to 3 spaces.
#

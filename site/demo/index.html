Type or paste a US address. doorplate reads it as you type, colors each part by what it decided the part is, and shows what it writes: the components, the USPS and RESO output, a match key and warnings. One line, any style; there are examples below the box. A whole spreadsheet of addresses can be parsed further down: Parse a CSV file.

The parser runs in your browser as WebAssembly. Nothing you type is sent anywhere. doorplate parses and formats addresses; it does not validate that an address exists or can receive mail.

Parse a CSV file

Have a spreadsheet of addresses? Pick the file, say which column holds the address (or which hold line 1, line 2, city, state and ZIP), and download the same file with the parsed parts added. The columns are the ones doorplate parse-file writes, with the prefix addr_.

The file stays on your computer. This page reads it in your browser, the parser runs here as WebAssembly in a background worker, and the result is built in memory and handed back as a download. Nothing is uploaded, and this page loads no analytics or other scripts. To check, open your browser's developer tools, choose the Network tab, and run a file: the only requests are this page's own files. doorplate parses and formats addresses; it does not validate that an address exists or can receive mail, and an alpha can be wrong: read the output before you use it.

# USPS Pub 28 notes

Sources for the Pub 28 tables and rules this library implements. Every USPS
rule in code must trace to an entry here (see `CONTRIBUTING.md`).

Publication: USPS Publication 28, *Postal Addressing Standards*,
<https://pe.usps.com/text/pub28/welcome.htm>. Table edition targeted: the
current online edition as of October 2026.

Formatting to Pub 28 is not validation. Nothing here checks that an address
exists or is deliverable.

## Lexicon tables

`crates/doorplate/data/*.toml` is compiled into static tables by `crates/doorplate/build.rs`
and read only through `Lexicons` (`crates/doorplate/src/lexicon.rs`).
`build.rs` rejects malformed tables: a spelling that maps to two entries, a
duplicate abbreviation or code, a form that is not a normalized key, or an
entry whose `forms` leave out its own name or abbreviation.

October 2026 against the live Pub 28 pages. `tools/pub28/verify.py` repeats the

### Non-Pub 28 spellings

Spellings that Pub 28 does not list are kept apart from
the Pub 28 forms, in `observed = [...]` lists with a source comment. Lookups
return them with `MatchKind::Observed` so the parser can report
`Warning::NonStandardAbbreviation`. Entries seen in field data, all from
Florida county data:

|---|---|---|

| `LP` | LOOP | suffixes |

| `SUIT` (35) | STE (SUITE) | units |

`AP` is also the Armed Forces Pacific state code; the tagger reads the
last line first, so `APO AP 96xxx` keeps it as the state.

Also `observed`, but taken from older transcriptions of the Pub 28 tables
rather than from field data: 20 suffix spellings that usaddress-scourgify and
the street-address gem list but the current Appendix C1 does not (for example
CRT for COURT, CR and CK for CREEK, LA for LANE, TR for TRAIL), and HANGAR,
the dictionary spelling of C2's "Hanger". See the per-entry comments in
`crates/doorplate/data/suffixes.toml` and `crates/doorplate/data/units.toml`.

State `aliases` (FLA, CALIF, ...) are traditional, pre-ZIP abbreviations,
not Pub 28 forms. They are accepted as input (`MatchKind::Variant`) and never
emitted.

### Lookup rules

- Keys are normalized by `lexicon::normalize_key`: uppercase, periods
  removed, whitespace runs collapsed, trimmed. So "P.O. Box" looks up as
  "PO BOX" and "N.E." as "NE". Data files must already be written in this
  normalized form (`build.rs` checks).
- Several spellings belong to more than one table (FL is a state and the
  FLOOR designator; KEY is a suffix and a designator; CR is circle (after a name) and county
  road; ST is street and saint; RD is the ROAD suffix, a rural route form and
  the ROAD highway prefix; ROUTE is a rural route form and a highway prefix). The lexicon answers each table on its own.
  Choosing between them by position is the tagger's job.
- State-dependent abbreviations (SR for State Road in Florida vs State Route
  elsewhere; RR for Ranch Road in Texas) are left out of the base tables, to
  be added by state data. A state's data can also read a base spelling differently:
  the base tables read `CR` as CIRCLE (an observed spelling), not CREEK, since the
  evidence says so (issue #108; `docs/states/fl.md`). A state data's `overrides.toml` can still read a base spelling differently.

## Parser rules

How the tagger (`crates/doorplate/src/tagger/`) reads an address, and where
each rule comes from. Rules from Pub 28 cite its section; the rest come from
shapes in real county data and are not USPS rules.

| Rule | Source |
|---|---|
| Read the last line (ZIP, state, city) first, then the delivery line from both ends: units and postdirectional from the right, house number and predirectional from the left. | Section 231 (parse from the right-most element). |
| Directionals: one or two words before the name are the predirectional, after the name and suffix the postdirectional, abbreviated to the Appendix B forms. A directional with no name left beside it is the name (`100 N ST`, `2 SOUTH ST`). The four two-letter forms written as two letter-words (`N W`, `N E`, `S W`, `S E`) are listed spellings in `directionals.toml`. | Sections 233.1, 233.21, 233.22; Appendix B; the spaced spellings seen in Florida address data (`8491 N W 17TH STREET`). |
| A one-letter directional right after a lone suffix word is part of the name, like any letter there (`AVENUE N`, `AVENUE G`). | Section 233.3 (letters used as alphabet indicators); Florida address data (`2108 AVENUE G`). |
| Suffix: the last word before units and postdirectional, when a name is left before it. Suffix words earlier in the line stay in the name (`EAGLES POINT CIRCLE`). | Section 234; Appendix C1. |
| Highway names: a prefix from `[[highway]]` right after the house number (or a predirectional) and followed by a route that starts with a digit. The prefix and route go in `highway`; later words are suffix, postdirectional or name (`HWY 11 BYPASS`, `US 41 SW`). `I10` and `IH280` are split by the tokenizer. | Section 237; Appendix F. |
| A state code or full name (not a traditional abbreviation or military code) right before a highway prefix goes in `highway.state` (`CA COUNTY RD 150`, `KY ST HWY 1`). A state right before an all-digit route, with no prefix, gets the HIGHWAY prefix (`KENTUCKY 440`, `KY 1207`). Tried after the plain and predirectional forms, so `NE HWY 5` keeps NE as a directional; the bare form skips states that are also directionals (`NE 5TH ST`). A state that is also a designator counts (`5100 FL 40 SUITE 100` is `FL HIGHWAY 40`): at the start of the street, a floor would leave no street name. | Appendix F and its note (a state that is the whole primary name, `OKLAHOMA AVE`, is the name). |
| County grid numbers are house numbers: digits and one or two compass letters, each followed by digits (`22W410`, `5S710` in DuPage County, IL; `W338S9739`, `S1749` in Wisconsin). | Appendix D2 (grid style addresses; it names the Salt Lake City form, not these); address data from other states (observed). |
| Two plain house numbers of three or more digits (`1309 1329 E VINE ST`, `4417 4417 N OAK AVE`): the first is the address's, the rest are left unparsed with `multiple_addresses`, only when a whole street follows on the line (an optional directional, a name word, the suffix ending the line). Rural grid streets named by number and direction (`1575 NORTH AVE`, `275 NORTH RD E`) and a split ordinal (`139 TH AVE`) keep the number in the name. | Florida address data (observed); Appendix D2 (grid names). |
| `P O BOX 4417 N E 9TH AVENUE`: a box word and number followed by a directional, an ordinal or number name and a suffix on the same line is a street address typed with stray box words; the box words go to `unparsed`. A named street (`PO BOX 12 N MAIN ST`) stays a box. | Florida address data (observed); no USPS rule. |
| House number `N-N`: one hyphenated number (`112-10`, `289-01`), unless the second part has as many digits and is larger (`1204-1206`), which raises `multiple_addresses`, except when the place's county is Queens, NY (next row). | Appendix D1, section 232; the range seen in observed data. |
| House number `N-N` with one trailing letter (**key-affecting**, held for the `k3`; issue #100): `12-34A`, `34-12A`, `123-45A` are one hyphenated number, as `12-34` and `1234A` are (it was no number at all: `missing_street_number`, the number left in the street name). One letter only, the limit of the plain-number rule; `12-34AB`, `12A-34` and `12-34-5A` stay as before, and `1204-1206A` is one number (a range has no letter). | Appendix D1, section 232 for the hyphenated form; the data: New York corporation records (4,160 start with a hyphenated number and a letter, 92% in Queens ZIP prefixes). Measured against the build before this rule: 4,998 keys change in the seven large sources (NY corporations 4,286, carrier census 560, amateur radio 84, IRS 44, Netsyms 16, NC voter 8, NAD 0), and `missing_street_number` is removed from every one. About 200 of the carrier census rows are non-US addresses (`k2n` keys), which now get their number. Corpus `hn-001` to `hn-009`. |
| In Queens, NY the part before the hyphen is the cross street and the part after it the building (`21-77 31ST ST`), so a hyphenated number with a larger second part is one address: `multiple_addresses` is not raised when the resolved place is in New York with county `QUEENS` and the range was the warning's only cause. A range elsewhere in New York (`20-22 W 45TH ST`, Manhattan) still warns. The number does not change; the key drops the hyphen (next row). Not applied when no place resolves (the city `QUEENS`, an unknown city and no ZIP). | Secondary sources only, no official one found: [StreetEasy](https://streeteasy.com/blog/queens-addresses-hyphenated-confusing-street-names/amp/) and [Steve Morse's Queens format page](https://stevemorse.org/census/changes/QueensFormat.htm) for the cross-street rule; measured in a New York state corporation registry (#99): 78% of the 45,575 `multiple_addresses` on an `N-N` number were in Queens ZIP prefixes. ### Display emitter (`emit/display.rs`, `ParsedAddress::to_display`, `to_long`)

Output: `DisplayAddress { line1, city, state, zip }`, plus `last_line()` and
`lines()`. **Neither form is a Pub 28 form**: they are for showing an address to
a person, so there is no Pub 28 source for the casing; the source of each rule is
the project's own style choice (issue #5). Use `to_usps()` for mail. The words
come from the same tables as the USPS emitter (`Directional::name()`,
`StreetSuffix::name()`, `UnitType::name()`), so the two never disagree on what a
word is.

### Notes on the emitter rules

Each was checked against the live Pub 28 text in October 2026 and again on
2026-10-17 (`tools/pub28/verify.py`).

1. **Punctuation.** Pub 28 lets punctuation be omitted except the ZIP+4 hyphen
   (222, A1). It keeps the hyphen in numbers and names, the slash in fractions,
   and a period in numbers such as `39.2 RD` (232), so the emitter keeps that
   period (corpus `p28-punct-001`). Apostrophes are on the 354 removal list, so
   `O'BRIEN` is `OBRIEN`. Hyphenated New York style numbers (`112-10`, `289-01`,
   Appendix D1) are one house number; only a range with a larger second number of
   the same length (`1204-1206`) raises `multiple_addresses`, unless the place is in Queens
   County (`21-77 31ST ST`, where the first part is the cross street).
2. **Secondary unit placement.** The unit goes at the end of the delivery line
   (213). When it does not fit, it goes on the line immediately above (213.3,
   343.1, 356). Pub 28 sets no line length (35), so `to_usps()` never wraps,
   `to_usps_wrapped(max_line)` wraps at the caller's limit, and
   `UspsAddress::lines()` gives mailpiece order.
3. **`#` for an unknown designator.** `# 4` with a space (213.2), and no `#` when
   the designator is known (213), so `APT #4` is `APT 4`.
4. **Last line.** `CITY ST ZIP` with at least one space (224; two preferred
   between state and ZIP, one used), no comma (222), ZIP+4 hyphen kept. City names
   are spelled out in full and abbreviated only from the City State file (223),
   which this library does not have, so no SAINT/ST or FORT/FT rule is applied.
5. **State inside a street name.** From Appendix F: a state code or name before a
   highway prefix (`CA COUNTY RD 150`, `KY ST HWY 1`), or before a route number
   alone (`KENTUCKY 440`, `KY 1207`, which take the HIGHWAY prefix), is kept as
   `Highway::state` and written as its code. A state that is the whole primary
   name (`OKLAHOMA AVE`) stays spelled out. Corpus `p28-highway-028` to
   `p28-highway-037`.
6. **Leading zeros.** Route numbers are kept as given by the emitters and by the
   parse; the key drops them (see the table above), so the USPS output of `RR 02`
   re-parses to the same key. Box numbers keep their zeros everywhere.
7. **Military and general delivery.** The 238.1 and 239 examples
   (`CPR 895 BOX 74` / `APO AE 09499-0001`, `UNIT 9900 BOX 0500` /
   `DPO AE 09701-0500`) and section 261 are matched by the corpus, which checks
   `usps` for these cases.
8. **Key punctuation rule.** Rule 1 of `docs/key-format.md` cites sections 222
   and 354.
9. **Appendix F.** Every example in the "Examples in Use" column gives its
   standard form, except `SR MM` (see Verification status).

Special forms (sourced):

- Highway contract route (section 251): emit `HC <route> BOX <box>`, e.g.
  `HC 68 BOX 23A`. Drop HIGHWAY CONTRACT, ROUTE, NUMBER, NO, STAR ROUTE and
  the pound sign, so `HIGHWAY CONTRACT ROUTE 68 BOX 23A`,
  `STAR ROUTE 68 BOX 23A` and `HC RTE #68 BOX 23A` all become
  `HC 68 BOX 23A`. The route and box values may hold letters (23A).
- Rural route (sections 241 to 245): emit `RR <route> BOX <box>`. Drop
  RURAL, NUMBER, NO and the pound sign; RFD and RD become RR (244). A
  leading zero on the route number is not needed (242). Keep hyphens in the
  box number (243 keeps them only when the ZIP+4 file has them; without the
  file, leave them as given). No street or town name on the RR line (245).
- PO Box (sections 281 to 283): emit `PO BOX <number>`. CALLER, FIRM CALLER,
  BIN, LOCKBOX and DRAWER become PO BOX (283). The box value may be a letter.
  Leading zeros in the box number are kept (282: the ZIP+4 file marks
  significant leading zeros, which are printed as zeros). Section 284: an
  address using the Post Office's street address with `# <box>` or
  `UNIT <box>` is a street address with a secondary unit, not a PO Box line.
- General delivery (section 261): emit `GENERAL DELIVERY`, spelled out.
- Highways (section 237, Appendix F): emit `[<state code>] <standard prefix> <route>`, for
  example `CR 1185` becomes `COUNTY ROAD 1185`, `HWY FM 1320` becomes
  `FM 1320`, `I10` becomes `INTERSTATE 10`, `US 41 SW` becomes
  `US HIGHWAY 41 SW`. Routes may hold letters (`COUNTY HIGHWAY 60E`,
  `STATE ROUTE MM`). After the route number, Appendix F abbreviates only the
  last word, as a normal suffix, and spells earlier ones out:
  `HWY 11 BYPASS` becomes `HIGHWAY 11 BYP`, `HIGHWAY 3 BYP ROAD` becomes
  `HIGHWAY 3 BYPASS RD`, and `HWY 66 FRONTAGE ROAD` becomes
  `HIGHWAY 66 FRONTAGE RD`. A state name inside the street name is written
  as its two-letter code (`KENTUCKY STATE HIGHWAY 625` becomes
  `KY STATE HIGHWAY 625`, and a bare `KENTUCKY 440` or `KY 1207` becomes
  `KY HIGHWAY 440` or `KY HIGHWAY 1207`), but a state name that is the
  whole primary name stays spelled out (`OKLAHOMA AVE`).
